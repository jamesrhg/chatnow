# ChatNow

ChatNow is a Nintendo 3DS chat client. Download `ChatNow.cia` from the
[latest release](https://github.com/jamesrhg/chatnow/releases/latest/)
and install it with a CIA installer on a homebrew-enabled console.
Or scan this with FBI (Remote install > Scan QR Code)
